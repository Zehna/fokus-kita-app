# FokusKita v2.0 — Productivity Suite (`Zehna/fokus-kita-app`)

Pembaruan besar (**Versi 2.0.0**) aplikasi manajemen tugas, statistik fokus harian, catatan cepat, dan pengatur waktu Pomodoro.

## Apa yang Baru di Versi 2.0?
- **Dashboard Statistik 4 Kartu**: Memantau Sesi Fokus Selesai, Total Waktu Fokus, Tugas Diselesaikan, dan Persentase Progres Harian.
- **Progress Bar Dinamis**: Visualisasi persentase penyelesaian tugas secara langsung.
- **Modul Kutipan Motivasi (`quotes.js`)**: Kutipan produktivitas dengan tombol pengacak.
- **Modul Efek Suara (`sound.js`)**: Efek suara otomatis berbasis Web Audio API saat menyelesaikan tugas atau menyelesaikan sesi Pomodoro.
- **Catatan Cepat (*Scratchpad*)**: Area catatan instan yang tersimpan otomatis di `localStorage`.
- **Pencarian, Kategori & Ekspor JSON**: Filter tugas berdasarkan kata kunci, kategori (`Dev`, `Git`, `Desain`, `Umum`), prioritas, dan unduh cadangan data ke `.json`.
